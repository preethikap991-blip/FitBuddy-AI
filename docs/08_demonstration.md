# Phase 8 – Project Demonstration

## 1. Introduction

Phase 8 demonstrates the working of the FitBuddy application from start to finish.

FitBuddy is an AI-based fitness plan generator developed using FastAPI, SQLite, HTML, CSS, and Google Gemini models.

The demonstration shows:

- Starting the application
- Entering user details
- Generating a fitness plan
- Viewing the generated plan
- Submitting feedback
- Generating an updated plan
- Viewing stored users
- Checking API documentation
- Checking the health API
- Running automated tests

---

## 2. Demonstration Objectives

The main objectives of the demonstration are:

1. To show that the FitBuddy application runs successfully.
2. To demonstrate user registration and input handling.
3. To demonstrate fitness plan generation.
4. To demonstrate feedback-based plan updating.
5. To demonstrate database storage.
6. To demonstrate the Admin / Coach View.
7. To demonstrate the available APIs.
8. To verify the application using automated tests.

---

## 3. Requirements

Before starting the demonstration, the following requirements should be available:

- Python
- Virtual environment
- Required Python packages
- FitBuddy project files
- SQLite database
- FastAPI
- Uvicorn

The project should be opened in Visual Studio Code.
